# task-wheel
是一款专为“选择困难”与“拖延症”打造的极简任务决策工具。面对繁杂的待办事项，本工具通过可视化抽奖机制，强制打破犹豫，帮你瞬间锁定当前唯一需要执行的任务，用“仪式感”代替“内耗”。 核心特色包括： 绝对公平：转盘扇区面积均等，每个任务中奖概率完全一致。 硬核重抽机制：当任务数无法整除100时，系统自动补齐空白扇区。若指针停在空白区，将自动触发重抽，直到选出有效任务，将悬念与公平完美结合。 压迫感反馈：抽奖结束后，系统会弹出极其醒目的 Warning 警告框，以大字标语“滚去 [任务名]”直击灵魂，用幽默且强硬的方式推你一把。 智能记忆：支持本地持久化存储，自动记住你历史填写的任务池，随时可手动增删改任务，无需重复输入。 只需点击转盘，把选择权交给概率，把执行力留给自己。
